# 베타 통합 테스트 체크리스트

테스트 계정 A·B·C·D로 진행합니다(계정 정보는 이 파일에 적지 않습니다).
각 항목 옆에 날짜와 결과(O / X / 메모)를 적고, X가 나오면 고친 뒤 그 항목만 다시 확인합니다.
화면은 폰(아이폰 사파리, 폭 360~390px)과 PC(1280px) 두 가지로 봅니다.
두 계정을 동시에 쓰려면 브라우저 하나는 일반 창, 하나는 시크릿 창으로 엽니다.

★ = 보안·개인정보 항목. 하나라도 X면 베타를 열지 않습니다.
🆕 = 57~73일차에 새로 들어온 기능(아직 실제 기기에서 한 번도 확인하지 않음).

---

## A. 빠른 실기기 시험 (약 40분, 가장 먼저)

57~73일차 기능은 가짜 데이터로만 시험했습니다. 아래만 먼저 확인하고, 나머지는 12/14~27 일괄 시험 때 합니다.
**평소 쓰는 PC**와 **아이폰 사파리**에서 각각 확인합니다. 결과는 "기기 / O·X / 무엇이 이상했는지(가능하면 캡처)"로 적어 주세요.

### A-1. 글쓰기 편집기 🆕 (가장 위험)
- [ ] 글자를 고르고 **B**를 누르면 바로 굵게 보임, 다시 누르면 풀림
- [ ] 제목·소제목·인용·목록·번호·구분선·링크 단추가 모두 동작하고, 커서가 이상한 곳으로 튀지 않음
- [ ] **한글을 빠르게 입력**해도 글자가 깨지거나 사라지지 않음(특히 아이폰)
- [ ] 되돌리기(↶)·다시 하기(↷), Ctrl+Z
- [ ] 사진 단추로 사진을 넣으면 커서 자리에 사진이 들어감, 사진 바로 아래 줄 맨 앞에서 Backspace로 지워짐
- [ ] 다른 사이트 글을 붙여 넣으면 서식 없이 글자만 들어감
- [ ] 게시한 글이 글 화면에서 쓴 모양 그대로 보임(굵게·제목·목록·사진 위치)
- [ ] 예전에 쓴 글을 ⋯ → 수정으로 열고, 아무것도 안 바꾸고 저장해도 내용이 그대로임

### A-2. 임시저장 🆕
- [ ] 쓰다가 **임시저장**을 누르면 숫자가 1 올라감
- [ ] 브라우저를 닫고(공용 PC면 **재부팅 후**) 다시 글쓰기를 열면 "임시저장 글이 있어요" → 이어 쓰기 됨
- [ ] 30초 동안 손대지 않으면 "자동으로 임시저장했어요"
- [ ] 게시하면 그 임시저장 글이 목록에서 사라짐

### A-3. 메인·검색 🆕
- [ ] 아래로 계속 내리면 글이 이어서 나오고, 끝에서 "모든 글을 다 봤어요"
- [ ] 카테고리 칩 2개 이상 동시 선택
- [ ] 검색창: **글 제목** / **닉네임** / **해시태그**. 해시태그는 앞에 `#` 고정, 스페이스 두 번 → `#` 추가, 여러 태그면 하나라도 달린 글
- [ ] 검색창을 마우스로 눌러도 파란(남색) 테두리가 생기지 않음

### A-4. ⋯ 메뉴 🆕
- [ ] 내 글: 수정·삭제·링크 복사 / 남의 글: 이 게시물 안 보기·신고·차단·프로필·링크 복사
- [ ] 폰에서는 아래에서 올라오는 시트, PC에서는 펼쳐지는 목록
- [ ] 댓글 ⋯: 삭제는 **댓글 쓴 사람과 글쓴이에게만** 보임 ★
- [ ] 이 게시물 안 보기 / 이 댓글 나한테 숨기기 → 되돌리기, 설정 → 내 활동 → 숨긴 게시물에서 다시 보기

### A-5. 알림·좋아요 🆕 (계정 A, B 두 개 필요)
- [ ] B가 A의 글에 댓글·좋아요 → A의 🔔에 숫자, 알림 화면에 두 줄, 열면 숫자가 사라짐
- [ ] 좋아요 숫자를 누르면 "좋아요한 사람" 목록에 B가 보임
- [ ] A가 설정 → 개인정보 보호 → 좋아요 수 공개를 **비공개**로 → B 화면에서 숫자가 사라짐(♡는 그대로 눌림), A 화면에서는 보임 ★
- [ ] A가 댓글 허용 범위를 **끄기**로 → B 화면에 "글쓴이가 이 글의 댓글을 막아 두었어요" ★ (시험 후 **모두**로 되돌리기)

### A-6. 설정 🆕
- [ ] 폰: 설정 → 분류 → 항목 → 항목 화면, "‹ 뒤로" 링크로 한 단계씩 돌아감
- [ ] 내 활동 → 내 글 내보내기: ZIP 파일이 받아지고 열림(PC·폰 모두)
- [ ] 보안 → 모든 기기에서 로그아웃: 이 기기가 로그아웃됨

### A-7. 인스타그램 앱 안 브라우저 🆕
인스타 DM이나 프로필 링크로 사이트 주소를 보내 놓고, **인스타 앱 안에서** 엽니다.
- [ ] 화면이 깨지지 않고 한국어/영어가 맞게 나옴
- [ ] 가입·로그인이 되고, 앱을 껐다 켜도 로그인이 유지됨(유지되지 않으면 메모)
- [ ] 글쓰기에서 사진 올리기가 됨

## B. 준비 (직접 해야 하는 것)

- [ ] **테스트 글 정리:** 테스트 계정 A~D를 설정 → 개인정보 보호 → 계정 공개 범위에서 **비공개**로(계정은 남겨 두고 피드에서만 사라짐). Operator 계정의 테스트 글은 ⋯ → 삭제
- [ ] **SMTP 설정 후:** 비밀번호 찾기 메일이 실제로 도착하고 링크로 새 비밀번호를 정할 수 있음
- [ ] **SMTP가 되면 Confirm email 켜기:** 새로 가입하면 "메일함을 확인해 주세요"가 뜨고, 메일의 링크를 누르면 로그인됨(가입 화면은 이 경우를 이미 처리함)
- [ ] Supabase 인증 설정의 사이트 주소(Site URL)와 이동 허용 주소에 `https://itsmetjdgus.github.io/tidnote/` 가 들어 있음(메일 링크가 엉뚱한 곳으로 가면 여기부터 확인)
- [ ] `@tidnote` 인스타그램 이름 확보(게시물은 12/25 이름 공개 후)

## C. 일괄 시험 (12/14~27)

### 0. 시작 전
- [ ] Supabase SQL Editor에서 `ops.sql` 블록 14~18 실행: 14·16은 0줄, 17은 `2027-01-01`, 18은 주석에 적힌 함수만 anon 실행 true
- [ ] `node check-i18n.js`, `node check-sri.js` 모두 `문제 없음`
- [ ] main의 최신 커밋이 GitHub Pages에 반영됨(바닥글·화면이 최신 코드와 같음)

### 1. 계정
- [ ] 가입: 만 14세·약관 동의를 체크하지 않으면 가입되지 않음
- [ ] 가입 → (메일 확인) → 로그인 → 로그아웃 → 다시 로그인
- [ ] 설정 → 보안 → 비밀번호 변경: 현재 비밀번호가 틀리면 바뀌지 않음
- [ ] 닉네임에 `@`를 넣으면 거부됨, 2~20자 제한
- [ ] 언어 바꾸기(한국어 ↔ English): 모든 화면 문구가 바뀌고, 다시 접속해도 유지됨. 처음 온 사람은 브라우저 언어를 따름

### 2. 글
- [ ] A-1 편집기 항목 전체, 카테고리 여러 개, 해시태그 여러 개(50개 제한), 사진 10장 제한
- [ ] 수정·삭제는 내 글에서만 보임. 다른 계정의 글 주소로 `write.html?id=`에 들어가도 수정되지 않음 ★
- [ ] 글 화면이 메인 카드와 같은 순서(프로필 → 날짜·카테고리 → 제목 → 본문 → 해시태그 → 좋아요·댓글 수)
- [ ] 해시태그를 누르면 그 태그의 글만 보이고, 검색창이 해시태그 모드로 채워짐

### 3. 사진 보호 ★
- [ ] 위치 정보(GPS)가 들어 있는 폰 사진을 올린 뒤, 내려받은 파일에 EXIF(위치·기기 정보)가 없음
- [ ] 글 사진 주소(`post-images`)를 복사해 1시간 뒤에 열면 열리지 않음(서명 주소 만료)
- [ ] 비공개 계정의 글 사진 주소를 로그아웃 상태나 팔로우하지 않은 계정에서 열면 열리지 않음
- [ ] 프로필 사진(`avatars`)과 소개글은 비공개 계정이어도 공개이고, 프로필 수정 화면의 안내 문구가 그 사실을 알려 줌

### 4. 비공개 계정 ★
- [ ] A를 비공개로 바꾸면, 로그아웃 상태와 B(팔로우 안 함)에게 A의 글·댓글·사진이 보이지 않음 (메인, 검색, 해시태그, 글 주소 직접 입력 모두)
- [ ] B가 A에게 팔로우 요청 → A의 알림에서 바로 수락 → B에게 "요청을 수락했어요" 알림, B에게 글이 보임
- [ ] 거절하면 계속 안 보이고, 요청 알림도 사라짐
- [ ] A가 B를 팔로워에서 삭제하면 B에게 다시 안 보임
- [ ] A를 공개로 되돌리면 대기 중이던 팔로우 요청이 자동으로 수락되고 글이 모두에게 보임
- [ ] 다른 사람은 A의 팔로워 수만 보고, 팔로잉 수와 목록은 A 본인만 봄

### 5. 차단 ★
- [ ] A가 B를 차단하면 서로의 팔로우가 풀리고, 서로의 글·댓글이 메인·검색·글 화면에서 보이지 않음
- [ ] 차단하면 두 사람 사이의 알림이 사라지고, 이후 서로의 행동이 알림으로 오지 않음
- [ ] 좋아요한 사람 목록에 차단한 사람이 보이지 않음
- [ ] B가 A의 프로필에 가면 "이 계정은 볼 수 없습니다", A가 B의 프로필에 가면 차단 안내와 해제 버튼
- [ ] B는 A를 다시 팔로우하거나 A의 글에 댓글을 달 수 없음 (화면에서도, 글 주소를 직접 열어도)
- [ ] 설정 → 개인정보 보호 → 차단한 계정에 B가 보이고, 해제하면 다시 보임(팔로우는 자동으로 돌아오지 않음)

### 6. 계정 삭제 흔적 ★
- [ ] D로 글(사진 포함)·댓글·좋아요·팔로우·의견·임시저장·숨긴 글을 만든 뒤 계정 삭제
- [ ] 다른 계정에서 D의 글·댓글·프로필이 모두 사라짐, D의 글 주소는 "글을 찾을 수 없습니다", D가 남긴 알림도 사라짐
- [ ] `ops.sql` 블록 11에서 D의 사진 파일이 남지 않음
- [ ] 같은 이메일로 다시 가입할 수 있음
- [ ] 테스트가 끝나면 D를 다시 만들어 둠(테스트 계정 A~D는 계속 사용)

### 7. 신고·운영
- [ ] 글·댓글·프로필 신고(⋯ → 신고 창)가 `ops.sql` 블록 1에 보임(자해 우려가 맨 위)
- [ ] 블록 4a(글 삭제) → 블록 6a(복구) → 블록 6c 점검이 모두 정상
- [ ] 블록 7a(정지) 후 그 계정이 로그인되지 않고, 7b(해제) 후 다시 로그인됨
- [ ] 설정 → 정보 → 의견 보내기가 블록 12에 보임
- [ ] 로그인하지 않은 상태의 신고 안내(이메일)가 맞는 주소로 적혀 있음

### 8. 약관
- [ ] DB의 약관 버전을 일부러 다르게 했을 때 재동의 창이 뜨고, 거부하면 로그아웃 (확인 후 원래대로)
- [ ] 약관·개인정보처리방침의 한/영 시행일이 같고, 내용이 서로 맞음(임시저장·숨긴 글·알림·좋아요 목록 문구 포함)

### 9. 화면·접근성
- [ ] 폰(360px): 가로로 밀리는 화면 없음, 헤더가 겹치지 않음, 입력칸을 눌러도 화면이 확대되지 않음(아이폰)
- [ ] 키보드만으로(Tab, Enter, Esc) 로그인 창·가입 창·계정 메뉴·⋯ 메뉴·글쓰기 서식 도구를 쓸 수 있고, 포커스 테두리가 보임
- [ ] 404 화면, 느린 인터넷(개발자 도구 Slow 4G)에서 "불러오는 중" 문구

### 10. 마무리
- [ ] X였던 항목을 모두 고치고 다시 확인함
- [ ] 테스트로 만든 글·댓글·신고·의견 정리(테스트 계정 A~D는 남김)
- [ ] 베타 안내문 확정 (데이터 초기화 가능 문구 포함 여부 결정)
