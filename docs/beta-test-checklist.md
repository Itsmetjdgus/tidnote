# 베타 통합 테스트 체크리스트 (12/14~27)

테스트 계정 A·B·C·D로 진행합니다(계정 정보는 이 파일에 적지 않습니다).
각 항목 옆에 날짜와 결과(O / X / 메모)를 적고, X가 나오면 고친 뒤 그 항목만 다시 확인합니다.
화면은 폰(아이폰 사파리, 폭 360~390px)과 PC(1280px) 두 가지로 봅니다.

★ = 보안·개인정보 항목. 하나라도 X면 베타를 열지 않습니다.

## 0. 시작 전

- [ ] Supabase SQL Editor에서 `ops.sql` 블록 14~18 실행: 14·16은 0줄, 17은 `2027-01-01`, 18은 주석에 적힌 함수만 anon 실행 true
- [ ] `node check-i18n.js`, `node check-sri.js` 모두 `문제 없음`
- [ ] main의 최신 커밋이 GitHub Pages에 반영됨(바닥글·화면이 최신 코드와 같음)

## 1. 계정

- [ ] 가입: 만 14세·약관 동의를 체크하지 않으면 가입되지 않음
- [ ] 가입 → 로그인 → 로그아웃 → 다시 로그인
- [ ] 비밀번호 찾기 메일이 실제로 도착하고, 링크로 새 비밀번호를 정할 수 있음 (SMTP 설정 후에만 가능)
- [ ] 설정에서 비밀번호 변경: 현재 비밀번호가 틀리면 바뀌지 않음
- [ ] 닉네임에 `@`를 넣으면 거부됨, 2~20자 제한
- [ ] 언어 바꾸기(한국어 ↔ English): 모든 화면 문구가 바뀌고, 다시 접속해도 유지됨

## 2. 글

- [ ] 글쓰기: 제목·본문·카테고리·태그·사진, 서식(굵게·제목·목록·링크), 미리보기, 글자 수
- [ ] 쓰던 중 새로고침해도 임시저장이 돌아옴. 게시·로그아웃하면 임시저장이 지워짐
- [ ] 수정·삭제는 내 글에서만 보임. 다른 계정의 글 주소로 `write.html?id=`에 들어가도 수정되지 않음 ★
- [ ] 메인: 최신순, 10개씩 페이지, 검색, 카테고리, 해시태그, 팔로잉 탭
- [ ] 댓글 쓰기·지우기(내 댓글, 내 글에 달린 댓글), 좋아요 누르기·취소

## 3. 사진 보호 ★

- [ ] 위치 정보(GPS)가 들어 있는 폰 사진을 올린 뒤, 내려받은 파일에 EXIF(위치·기기 정보)가 없음 (사진은 업로드 전에 다시 그려 저장하므로 지워져야 정상)
- [ ] 글 사진 주소(`post-images`)를 복사해 1시간 뒤에 열면 열리지 않음(서명 주소 만료)
- [ ] 비공개 계정의 글 사진 주소를 로그아웃 상태나 팔로우하지 않은 계정에서 열면 열리지 않음
- [ ] 프로필 사진(`avatars`)과 소개글은 비공개 계정이어도 공개이고, 프로필 수정 화면의 안내 문구가 그 사실을 알려 줌

## 4. 비공개 계정 ★

- [ ] A를 비공개로 바꾸면, 로그아웃 상태와 B(팔로우 안 함)에게 A의 글·댓글·사진이 보이지 않음 (메인, 검색, 해시태그, 글 주소 직접 입력 모두)
- [ ] B가 A에게 팔로우 요청 → A가 수락하면 B에게 글이 보임, 거절하면 계속 안 보임
- [ ] A가 B를 팔로워에서 삭제하면 B에게 다시 안 보임
- [ ] A를 공개로 되돌리면 대기 중이던 팔로우 요청이 자동으로 수락되고 글이 모두에게 보임
- [ ] 다른 사람은 A의 팔로워 수만 보고, 팔로잉 수와 목록은 A 본인만 봄

## 5. 차단 ★

- [ ] A가 B를 차단하면 서로의 팔로우가 풀리고, 서로의 글·댓글이 메인·검색·글 화면에서 보이지 않음
- [ ] B가 A의 프로필에 가면 "이 계정은 볼 수 없습니다", A가 B의 프로필에 가면 차단 안내와 해제 버튼
- [ ] B는 A를 다시 팔로우하거나 A의 글에 댓글을 달 수 없음 (화면에서도, 글 주소를 직접 열어도)
- [ ] 설정 → 차단한 계정 목록에 B가 보이고, 해제하면 다시 보임(팔로우는 자동으로 돌아오지 않음)

## 6. 계정 삭제 흔적 ★

- [ ] D로 글(사진 포함)·댓글·좋아요·팔로우·의견을 만든 뒤 계정 삭제
- [ ] 다른 계정에서 D의 글·댓글·프로필이 모두 사라짐, D의 글 주소는 "글을 찾을 수 없습니다"
- [ ] `ops.sql` 블록 11에서 D의 사진 파일이 남지 않음 (남으면 계정 삭제의 사진 정리 확인)
- [ ] 같은 이메일로 다시 가입할 수 있음
- [ ] 테스트가 끝나면 D를 다시 만들어 둠(테스트 계정 A~D는 계속 사용)

## 7. 신고·운영

- [ ] 글·댓글·프로필 신고가 `ops.sql` 블록 1에 보임(자해 우려가 맨 위)
- [ ] 블록 4a(글 삭제) → 블록 6a(복구) → 블록 6c 점검이 모두 정상
- [ ] 블록 7a(정지) 후 그 계정이 로그인되지 않고, 7b(해제) 후 다시 로그인됨
- [ ] 설정 → 의견 보내기가 블록 12에 보임
- [ ] 로그인하지 않은 상태의 신고 안내(이메일)가 맞는 주소로 적혀 있음

## 8. 약관

- [ ] DB의 약관 버전을 일부러 다르게 했을 때 재동의 창이 뜨고, 거부하면 로그아웃·임시저장 삭제 (확인 후 원래대로)
- [ ] 약관·개인정보처리방침의 한/영 시행일이 같고, 내용이 서로 맞음

## 9. 화면·접근성

- [ ] 폰(360px): 가로로 밀리는 화면 없음, 헤더가 겹치지 않음, 입력칸을 눌러도 화면이 확대되지 않음(아이폰)
- [ ] 키보드만으로(Tab, Enter, Esc) 로그인 창·가입 창·계정 메뉴·글쓰기 서식 도구를 쓸 수 있고, 포커스 테두리가 보임
- [ ] 404 화면, 느린 인터넷(개발자 도구 Slow 4G)에서 "불러오는 중" 문구
